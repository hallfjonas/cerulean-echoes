# Task: Shared state between stems

## Description
A stem names states it publishes and states it reads; the track keeps the registry; a read with nothing published gives
its default.

## Acceptance Criteria
- [ ] `publishes` / `reads` in the stem schema and the loader; `track.shared` registry with per-bar values
- [ ] A reader works with any stem that publishes the name, and with none (default)
- [ ] Gating order: a published value is made before the stems that read it in the same 16th
- [ ] Feature test: a publisher and a reader stem, the reader with and without the publisher

## Technical Details
`sc/lib/stems.scd`, `stemtrack.scd`, `steps.scd` (order of the stems in a 16th).
