# Task: Loader and engine for span 2

## Description
`stemColumn` and the track loader take a stem with `span: 2`: two CC sets, one strip, one `notes`, level and gate from
the second column's fader.

## Acceptance Criteria
- [ ] `.track` slot rules: the second slot is reserved, a stem in it is refused with a clear message
- [ ] Column code reads both sets (`col.knob2`, `col.held2`, `col.press2`); hooks for both columns' knobs and buttons
- [ ] Strip level, gate and the Break read the playing column's fader; the first column's fader acts as a control only
- [ ] `stemTrackTags` makes the six + six `@ctl` lines; `~ce.stemSlots` and every single stem unchanged
- [ ] A test stem pair as fixtures next to the 090 demo track and a feature test in `tools/sc-test/run.scd` (loads, plays, both knob sets reach the code, the gate)

## Technical Details
`sc/lib/stems.scd`, `sc/lib/stemtrack.scd`, `sc/lib/stemkit.scd`, `tools/sc-test/run.scd`. Check `gh pr list` for changes to the slot model first.
