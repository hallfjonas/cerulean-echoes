# Task: Sample Designer

## Description
Build a new sample (library sound) on the whole LC. Two fixed setups: drum machine and synthesizer. Projects are files
that can be saved, copied and exported.

## Acceptance Criteria
- [x] Machine schema on the LC: columns = blocks in the signal path, row 1 / 2 / 3 = main / shape and time / fine and
      modulation, fader = block level, button 1 = block on/off, button 2 = block type; column 8 = audition pattern,
      master, Save; `@ctl` texts for the MIDI panel
- [x] Drum machine (one drum voice: oscillator + noise, pitch and amp envelopes, filter, drive) and synthesizer (two
      oscillators, filter, envelopes, LFO, chorus / drive), each with an audition pattern that has rhythm
- [x] Project file `sc/lab/samples/<name>.sample.json` (format 1, schema): setup, sources, block chain, control values,
      audition pattern; also used by free arrangements (006)
- [x] Player: projects listed under Lab; Save, Save as (copy), Load
- [x] Export: `sc/sounds/<name>.scd` in the library format (named parameters stay live, `~ce.checkSound` passes) and a
      WAV render in `samples/` via `sc/tools/render.scd`
- [x] Feature tests: project loads, Save as copies, export writes a sound that loads and a WAV

## Technical Details
Takes over the machine lab of sc-migration 009. Machine ideas: `sc/PLAN-STEM-LIBRARY.md` ("Maschinen"), and
`sc/ANLEITUNG-LAB-GUI.md` for earlier Qt experiments (play through the player and the LC instead).

## Implementation notes (2026-11-20)
- Docs: `docs/features/sample-designer.md`. Blocks (kinds, knobs, types, the two setups): `sc/lab/samples/blocks.json`;
  their sound: `sc/lab/samples/machine.scd` (one SynthDef per block chain, every value a live control); the LC side:
  `sc/lib/designer.scd` (`~ce.sampleProject`), loaded by `sc/engine.scd` and `sc/tools/render.scd` for a
  `.sample.json` path.
- Project = `sources` + `chain` of blocks, setup `drum`, `synth` or `free` (any blocks, at most 7, at most one `env`
  and one `lfo`): 006 writes `free` projects with the same blocks. A second envelope in the synth is the LFO's type
  Envelope.
- Node: `tools/sound-lab/sample-project.mjs` (check, save, save as, export), CLI `npm run sample-lab`; player routes
  `tools/trajectory/sample-lab.mjs`, sidebar `sample-lab-ui.mjs`. The export embeds a copy of `machine.scd`, so an
  exported sound never changes with the machine; WAV in `samples/sound-lab/`.
