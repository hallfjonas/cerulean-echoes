# Task: Stem format 2

## Description
The 009 pilot (003) needed the code hatch in 13 of 14 columns. Format 2 moves the common cases into JSON so the Stem
Designer and Track Designer can edit stems without writing SC code. Decided by the user on 2026-11-21.

## Acceptance Criteria
- [x] Format 2 in `stem.schema.json`, `docs/features/stems.md` and `check-stems` (format 1 files keep passing or are
      migrated in the same PR; no silent break)
- [x] Kits: a pattern's notes pick a file of the sample (clap, hats, congas)
- [x] Layers: several sounds per hit with a cross-fade knob (sub, harmony, bass, keys)
- [x] Envelopes per pattern and a length knob relative to the note (sub Length)
- [x] Complexity as layers switched on from a knob value (vibraphone, flute, brass, strings, guitar)

  format 1 stem is one layer), `sc/lib/stemtrack.scd` (boost level, trim map, own echo on the strip).
