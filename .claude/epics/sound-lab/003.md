# Task: Pilot: 009-house as a stem track

## Description
Extract the 14 columns of `sc/tracks/009-house/009-house.scd` into stems and rebuild 009 as a stem track that plays
the same. Proves the format on a real track.

## Acceptance Criteria
- [ ] 14 stem versions in `sc/stems/<sample>/`, each passing `check-stems`, with metadata filled in
- [ ] `sc/tracks/009-house/009-house.track.json` next to `009-house.scd` (the `.scd` stays until the players accept
      the stem version)
- [ ] Event-by-event match against `009-house.scd` over the 009 auto-perform script (`tools/sc-port` compare); any
      difference explained and accepted by the user
- [ ] Note in the PR: how many columns needed the code hatch and why; if more than half, propose a format change
      before 007

code-hatch cases.
