# Task: Pilot: 009-house as a stem track

## Description
Extract the 14 columns of `sc/tracks/009-house/009-house.scd` into stems and rebuild 009 as a stem track that plays
the same. Proves the format on a real track.

## Acceptance Criteria
- [x] 14 stem versions in `sc/stems/<sample>/`, each passing `check-stems`, with metadata filled in
- [x] `sc/tracks/009-house/009-house.track` next to `009-house.scd` (the `.scd` stays until the players accept
      the stem version)
- [ ] Event-by-event match against `009-house.scd` over the 009 auto-perform script (`tools/sc-port` compare); any
      difference explained and accepted by the user (match: done; acceptance of the differences below: open)
- [x] Note in the PR: how many columns needed the code hatch and why; if more than half, propose a format change
      before 007

## Technical Details
Columns are cut along the `@ctl` blocks. Keys (2:2) with its four sounds and the Complexity steps are the likely
code-hatch cases.

## Notes (done)
- Stems (`sc/stems/`): `kick909/…-drop-out-2` (JSON, parent the example kick), `sdNoise`, `subSine`, `bassFM`,
  `clap909`, `hats909`, `congas727`, `sdSupersaw`, `houseKeys`, `vibraphone`, `flute`, `brassSection`,
  `stringSection`, `strat` (column code `.scd` next to each). Frame: `sc/tracks/009-house/009-house-frame.scd`.
- Format additions (docs/features/stems.md): column code (a stem `code` file returning an Event: `notes`, `start`,
  `update`, `b1`, `gate`, `states`, `maps`, `strip`), `sample.extra`, wrapper sounds (`files` key), frame `chordAtK`
  and `nextChords`, Chords on a chords stem steps the frame's progressions, Tension echo only on stems with an echo
  send, `sc/lib/stemkit.scd`.
- Code hatch: 13 of 14 columns (more than half: format 2 proposal in docs/features/stems.md, "The 009 pilot").
- Comparison (`tools/sc-port/stem-compare.mjs`, start values as in the docs): `dance-floor.json` 192 bars, 17 368
  notes, every stem equal; `every-button.json` 80 bars equal; `sc-port/scenarios/009-stem-check.json` 48 bars equal
  but for difference 1. Audio (null test, gains 1): Mode 1, keys, flute, brass, strings, guitar bit-identical; the
  harmony differs only by the supersaw's random phases (two renders of the `.scd` differ the same way).
- Loudness: `tools/stems/stem-loudness.mjs`, target −13.7 LUFS-M (009 kick) + role offset; gains set (0.85 … 3.67).
- Tests: `tools/stems/check-stems.test.mjs` (column code, extra sounds, wrappers), `tools/sc-test/run.scd` (009
  stem track loads and every column plays; Chords steps the frame's progressions).
