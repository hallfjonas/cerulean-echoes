# Task: Stem Designer

## Description
Compare up to 14 versions of a stem on the LC columns (Mode 1 and Mode 2, columns 1-7) against a running track, and
promote the winner into the library.

## Acceptance Criteria
- [x] Project file `sc/lab/stems/<name>.stemlab.json` (format 1, schema): columns → stem versions (library files or
      drafts inside the project), optional context track (harmony, tempo, which of its stems play along)
- [x] Column 8 global: A/B between the selected column and the context track's stem, Promote; others as in tracks
- [x] Player: projects listed under Lab; Save, Save as (copy), Load
- [x] Promote writes a new stem version (naming rule, `parent` set, `check-stems` passes); never overwrites
- [x] 14 columns + context track play without dropouts (measured 2026-11-21 on an M2 Pro: all 14 009 stems plus
      backing 1:1, 1:3, 1:4, faders 0.8, all knobs 0.7, ~1 min at 124 BPM: scsynth 13-15 % of one core, sclang
      15-18 %, no late / underrun lines in the engine log; the M2 Air is not measured)
- [x] Feature tests: load, Save as, promote

## Technical Details
Takes over the options lab and promote of sc-migration 009. Builds on `sc/lib/stems.scd` and `stemtrack.scd`.

## Decisions (2026-11-21)
- Context track = frame only (tempo, chords, chapters, global column) plus backing: the stems of the slots in
  `context.backing` play on slots `b:1…` with CCs above 127 (no controller sends them), faders at 1. Candidates fill
  the 14 slots; the context stem of a slot is the A/B partner.
- Column 8: button 1 (Chapter's CC) = A/B, button 2 (Break's CC) = Promote; the chapter is `context.chapter`.
- A/B uses `~ce.swapProblem`: a candidate with another mixer strip than the context stem reports it and stays.
- A draft's code files lie next to its `parent` stem, else next to the project.
- Promote works on drafts only (a library stem is a version already); the draft column becomes the library ref.
