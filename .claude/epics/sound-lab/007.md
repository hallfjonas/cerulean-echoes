# Task: Stem Designer

## Description
Compare up to 14 versions of a stem on the LC columns (Mode 1 and Mode 2, columns 1-7) against a running track, and
promote the winner into the library.

## Acceptance Criteria
- [ ] Project file `sc/lab/stems/<name>.stemlab.json` (format 1, schema): columns → stem versions (library files or
      drafts inside the project), optional context track (harmony, tempo, which of its stems play along)
- [ ] Column 8 global: A/B between the selected column and the context track's stem, Promote; others as in tracks
- [ ] Player: projects listed under Lab; Save, Save as (copy), Load
- [ ] Promote writes a new stem version (naming rule, `parent` set, `check-stems` passes); never overwrites
- [ ] 14 columns + context track play without dropouts on the M2 Air (measured, gating as in tracks)
- [ ] Feature tests: load, Save as, promote

## Technical Details
Takes over the options lab and promote of sc-migration 009. Builds on `sc/lib/stems.scd` and `stemtrack.scd`.

## Dependencies
003 (stems of a real track to start from), 004 (library list).
