# Task: Stem swap in the player

## Description
Click a column in the MIDI panel, choose a stem from the library, hear it.

## Acceptance Criteria
- [x] Click on a column's name in the MIDI panel (stem tracks only) opens a drawer: library stems of the column's role,
      filters for genre, energy, tags; current version marked
- [x] Pick → the stem plays from the next bar, other columns keep playing (fallback: reload with a short gap, said in
      the UI)
- [x] The track file is not changed; "Save as" writes a new track file with the swaps; "Revert" restores
- [x] The column click goes through a selection registry (`tools/trajectory/selection.mjs`, kind `column` with
      track, slot, stem version), the one llm-support's Claude drawer will reuse
- [x] Feature test: swap via the endpoint changes the slot, Save as writes the file, the original is unchanged

## Technical Details
`tools/trajectory/player.html` / `ui.css`, `server.mjs` (`POST /swap`, `POST /track/save-as`), swap hook from 002.
Conflicts with 007 on the player's Lab buttons (same files).

## Notes (done)
- Endpoints (`tools/trajectory/stem-swap.mjs`, routed in `server.mjs`):
  `GET /swap?track=<id>` → `{ track, playing, slots: { '1:1': { stem, role, file } } }`;
  `POST /swap { track, slot, stem }` → `{ track, slot, stem, mode: 'next-bar' | 'reload', reason?, slots }`;
  `POST /swap/revert { track }` → `{ track, mode: 'next-bar' | 'reload' | 'none', slots }`;
  `POST /track/save-as { track, name? }` → 201 `{ id, name, file, slots }`, 409 if the folder exists.
- Selection registry `tools/trajectory/selection.mjs`: `createSelection()` → `select(item)`, `clear()`, `current()`,
  `on(kind | '*', fn)`; `KINDS.column = ['track', 'slot', 'stem']`, `columnSelection({ track, slot, stem })`.
- Live vs reload is decided in SC (`~ce.swapProblem`): the slot's strip is made at the load, so a stem that wants
  another strip shape (echo send, lanes, map buses, own strip of column code) reloads the track with it. Tested: kick
  v1 ↔ v2 live, keys → vibraphone live (sc-test), warm bass ↔ bass FM reload. Today's library has few same-role
  alternatives (kick 2 versions, bass 2, lead 4), so most columns list only their own stem.
- Keys hook leak fixed: hooks and latches made in `startCol` are owned by the column (`~ce.owning`) and dropped when
  it is swapped out (`~ce.dropHooks`); sc-test checks it on 009's keys.
- Save as copies the frame next to the new track (`<name>-frame.scd`; the format wants the frame in the track's
  folder). Open question: reference the original frame instead (format change)?
- The drawer was not opened in a browser in this task (UI checked by syntax only).
