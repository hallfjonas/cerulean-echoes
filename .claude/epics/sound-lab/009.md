# Task: Stem swap in the player

## Description
Click a column in the MIDI panel, choose a stem from the library, hear it.

## Acceptance Criteria
- [ ] Click on a column's name in the MIDI panel (stem tracks only) opens a drawer: library stems of the column's role,
      filters for genre, energy, tags; current version marked
- [ ] Pick → the stem plays from the next bar, other columns keep playing (fallback: reload with a short gap, said in
      the UI)
- [ ] The track file is not changed; "Save as" writes a new track file with the swaps; "Revert" restores
- [ ] The column click goes through a selection registry (`tools/trajectory/selection.mjs`, kind `column` with
      track, slot, stem version), the one llm-support's Claude drawer will reuse
- [ ] Feature test: swap via the endpoint changes the slot, Save as writes the file, the original is unchanged

## Technical Details
`tools/trajectory/player.html` / `ui.css`, `server.mjs` (`POST /swap`, `POST /track/save-as`), swap hook from 002.
