# Task: SC stem loader and add-on library

## Description
SC plays a `.stem` in any column and a stem track (`.track`) as a live track in the player.

## Acceptance Criteria
- [x] `sc/lib/stems.scd`: load a stem → column with sample + preset, pattern cycle on button 1, knobs on control buses
      (act on sounding notes), fader Level, add-on on button 2, standard global inputs (Fog, Thin, Tension, Break,
      harmony)
- [x] `sc/lib/addons.scd`: the add-ons collected in 001 as named, parameterised blocks
- [x] Code hatch: `"code"` files load and return the same event shape
- [x] `sc/lib/stemtrack.scd`: slots `1:1`-`2:7` + tempo, harmony / chapters, global column; `@ctl` texts generated from
      the stems so the MIDI panel, `check-perform` and the auto-perform scripts work unchanged
- [x] Catalogue lists stem tracks (`engine: 'sc'`); a small stem track of the two example stems plays in the player
- [x] Silent columns are gated (no CPU when fader or global level is 0)
- [x] Feature tests: a stem loads, Pattern cycles, a knob reaches its bus, the add-on fires

## Technical Details
Reuse `sc/lib/controls.scd`, `mixer.scd`, `mini.scd`, `steps.scd`. Swap hook for 009: replace one slot's column at
the next bar without touching the others (design it here, used in 009).

## Notes (done)
- Example stem track `sc/tracks/090-stem-demo/` (kick909 on 1:1, bassWarm on 1:4); the player lists stem tracks with
  `stems: true` (`<id>-stems` beside an `.scd` of the same name, for the 003 pilot).
- Swap hook for 009: `~ce.swapSlot(slot, ref, load)`, next bar, filled slots only (an empty slot has no strip).
- `@ctl` lines are made twice, in SC (`~ce.stemTrackTags`) and Node (`tools/stems/stem-tags.mjs`, for
  check-perform); `npm test` compares them.
