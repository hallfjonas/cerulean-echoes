# Task: SC stem loader and add-on library

## Description
SC plays a `.stem` in any column and a stem track (`.track`) as a live track in the player.

## Acceptance Criteria
- [ ] `sc/lib/stems.scd`: load a stem → column with sample + preset, pattern cycle on button 1, knobs on control buses
      (act on sounding notes), fader Level, add-on on button 2, standard global inputs (Fog, Thin, Tension, Break,
      harmony)
- [ ] `sc/lib/addons.scd`: the add-ons collected in 001 as named, parameterised blocks
- [ ] Code hatch: `"code"` files load and return the same event shape
- [ ] `sc/lib/stemtrack.scd`: slots `1:1`-`2:7` + tempo, harmony / chapters, global column; `@ctl` texts generated from
      the stems so the MIDI panel, `check-perform` and the auto-perform scripts work unchanged
- [ ] Catalogue lists stem tracks (`engine: 'sc'`); a small stem track of the two example stems plays in the player
- [ ] Silent columns are gated (no CPU when fader or global level is 0)
- [ ] Feature tests: a stem loads, Pattern cycles, a knob reaches its bus, the add-on fires

## Technical Details
Reuse `sc/lib/controls.scd`, `mixer.scd`, `mini.scd`, `steps.scd`. Swap hook for 009: replace one slot's column at
the next bar without touching the others (design it here, used in 009).
