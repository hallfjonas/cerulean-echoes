# Task: Script format v2: meta, sections, Launchkey steps

## Description
Extend the auto-perform script format with optional meta info and sections, and with Launchkey steps (keys, pads,
LK knobs / mod wheel), in the browser player and the Node scenario tool. Old scripts stay valid.

## Acceptance Criteria
- [x] Optional fields `title`, `bars`, `mood`, `sections: [{ name, from, to, intent }]`
- [x] Steps `{ bar, keys, velocity?, length? }`, `{ bar, pad }` (36-51), `{ bar, lk, value, ramp? }` (CC 1, 31-38)
- [x] Virtual Launchkey input in `midi.mjs`; 009 or 010 plays scripted keys on `stemLK` and fires pads (checked in
      the browser pane) — input built and checked in Node (stubbed navigator); the browser pane check is open

- [x] `check-perform` validates the new fields; `every-button.json` and `spike-run.json` pass unchanged
- [x] README "Auto-perform" section documents the format
