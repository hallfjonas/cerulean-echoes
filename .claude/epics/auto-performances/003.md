# Task: Design template and feedback log format

## Description
Write the template every performance design follows and the format of the per-track feedback log, so loop 1 (design)
and loop 2 (sound) are reviewed the same way on every track.

## Acceptance Criteria
- [ ] `tools/trajectory/perform/design-template.md` with: meta (title, bars, minutes at the track's BPM, mood, story
      in two lines, reference tracks from `docs/references.md`), section table (name, bars, LC controls that move by
      their `@ctl` names, Launchkey use, intent), risks (CPU peak, clipping, silent stretches), open questions
- [ ] Feedback log format: rounds `## Loop 1 / Round N` and `## Loop 2 / Round N` with the user's words, what
      changed, decision (approved / again); approval line is explicit
- [ ] Short note on how the agent prepares each track: `npm run track-map`, layout PDF / `@ctl` tags,
      `--view`, existing `feedback.md` in the track folder

## Technical Details
Plain Markdown; labels and section names English and short (CLAUDE.md "Labels").
