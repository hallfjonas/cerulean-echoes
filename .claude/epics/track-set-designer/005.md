# Task: Set format and SC set engine

## Description
A set file and the SC engine that plays it as one session: the playing track's columns live, the picked track
preloaded, a transition that swaps slot by slot at bar lines, switches frame and rig, and glides the tempo.

## Acceptance Criteria
- [ ] Set file `sc/sets/<id>/<id>.set` (format 1, schema `sc/sets/set.schema.json`, check in `check-stems`): name,
      about, tracks (unique stem track ids, in order), `start` (default the first), `transitionBars` (default 8),
      `phraseBars` for picks (default 8), optional `slotOrder` (default by role: pad / texture → sub / bass → drums →
      lead / keys / chords; empty-to-empty slots skipped)
- [ ] `sc/lib/stemset.scd`: loads the set; one server session; `~ce.setPick(index)` sets the pending track,
      preloads its sounds, samples and state buses; at the next phrase the transition runs: one slot group per step,
      each slot via the swap path; frame (chords, chapters, Chapter latch) and rig switch at the middle bar; tempo
      glides over `transitionBars`
- [ ] Slots: new stem into an empty slot gets a strip; a stem leaving into an empty slot fades out over one bar; a
      strip mismatch gets a new strip node next to the old and a one-bar crossfade, the old node freed after it
- [ ] Global column 8 keeps working through the transition (Fog, Thin, Tension, Master; Chapter and Break of the
      playing track; a pick during a transition waits for its end)
- [ ] Gating: a slot that finished leaving is not asked any more; the leaving track's unused buffers freed after the
      transition
- [ ] `engine.scd` and `render.scd` load `.set`; `render.scd` accepts picks in a scenario (`pick` at bar n)
- [ ] Feature tests (`sc-test/run.scd`): a 3-track set (009, 090, a test track) loads, a pick at bar 4 ends with every
      slot of the new track playing, no slot silent more than one bar unless empty in the new track, the tempo ends at
      the new track's
- [ ] CPU measured on the M2 Air in the player through one transition (with the user)

## Technical Details
Builds on `~ce.swapSlot`, `switchSlot`, `swapProblem`, `soundMsgs`, `stateMsgs` (`sc/lib/stemtrack.scd`) and the
mixer (`sc/lib/mixer.scd`). Build the strip replacement first, alone, with a test. Echo times are in beats
(`ownDelay`): recompute them as the tempo glides. Test track: a small stem track under `sc/tracks/` or a fixture in
`tools/` (decide in the PR; prefer a fixture if it is only for tests).
