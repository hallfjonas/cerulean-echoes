# Task: Spike: LC XL 3 Track ◄ ► buttons

## Description
Find out what the LC XL 3 Track ◄ ► buttons (and Page ▲ ▼, for later) send while the device is in custom mode 1 or 2:
nothing, a CC or note on the `LCXL3 … MIDI` port, or only on the `DAW` port; whether Novation Components can give
them a CC in a custom mode; whether a press changes the device's mode or page.

## Acceptance Criteria
- [ ] A small MIDI monitor (SC `MIDIFunc.trace` script in `sc/tools/` or a Node script in `tools/`) that lists every
      message from every LCXL3 port with its port name
- [ ] The user presses Track ◄, Track ►, Page ▲, Page ▼ in Mode 1 and Mode 2 (and once with the DAW port open);
      results written into `midi-layouts/devices.md` (port, message, channel, number, value on press/release)
- [ ] Decision recorded in the epic: Track ◄ ► usable as is, usable after a Components change (which), or not usable
      (then the fallback is chosen with the user and task 006 updated)

## Technical Details
No track or engine changes. Needs the user and the device.

## Dependencies
None.

## Effort Estimate
- Size: S
- Hours: 2 (plus 15 minutes with the device)

## Definition of Done
- [ ] Monitor committed, devices.md updated, decision in the epic
- [ ] Reviewed in the PR; task and epic status updated in the same PR
