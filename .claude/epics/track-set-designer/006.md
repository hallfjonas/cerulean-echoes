# Task: Live next track

## Description
Pick the next track on stage with Mode 2, column 8, button 1 (CC 92), named Next track, and see it on the LC view and
the SC panel. The LC XL 3 stays in standalone (MIDI) mode; Track ◄ ► and Page ▲ ▼ are not used (001).

## Acceptance Criteria
- [ ] In a set, CC 92 cycles the pending next track in set order (wraps; landing on the playing track again = stay,
      no transition); presses from every connected LC XL 3 count; the pick applies at the next phrase (`phraseBars`);
      a pick during a transition waits for its end
- [ ] CC 92 is no longer an alias of Chapter (CC 44) in a set; Mode 1 column 8 button 1 stays Chapter; every other
      column 8 control still aliases across both modes; outside a set nothing changes
- [ ] LC view (`▣ LC big`) and SC panel: set head with the playing track, the pending one, transition progress
      (step n of m); short English labels; the Mode 2 column 8 button 1 cell reads "Next track"
- [ ] `@ctl` text for the button (about 50 characters); `check-perform` knows it
- [ ] Auto-perform scripts v2 can press it (virtual `LCXL3 Auto`), so a set can be tried without the device
- [ ] Feature tests: latch (press, wrap, stay), Chapter on CC 44 unaffected, a scripted pick starts a transition
- [ ] Tried live with the user on the device

## Technical Details
Stem tracks alias CC g + 48 to g for every global control (`aliases` in `sc/lib/stemtrack.scd`); the set removes the
alias for 92 → 44 only. `ce.cycleButton` and `ce.latch` as for Chapter.
