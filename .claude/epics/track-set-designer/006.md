# Task: Live next track

## Description
Pick the next track on stage with the LC XL 3 Track ◄ ► buttons (as measured in 001) and see it on the LC view and
the SC panel.

## Acceptance Criteria
- [ ] Track ► / ◄ cycle the pending next track in set order (wraps; landing on the playing track again = stay); from
      every connected LC XL 3, last press wins; applies at the next phrase (`phraseBars`)
- [ ] LC view (`▣ LC big`) and SC panel: set head with the playing track, the pending one, transition progress
      (step n of m); short English labels
- [ ] `@ctl` (or a new `@set` tag) texts for the two buttons; `check-perform` knows them
- [ ] Auto-perform scripts v2 can press them (virtual `LCXL3 Auto`), so a set can be tried without the device
- [ ] Feature tests: latch (press, wrap, stay), a scripted pick starts a transition
- [ ] Tried live with the user on the device
