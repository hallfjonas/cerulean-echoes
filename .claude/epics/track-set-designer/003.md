# Task: Track Designer

## Description
Build a stem track in the player: stems onto any of the 14 slots, track settings, a frame from a template track, the
Launchkey rig; publish it as a new stem track.

## Acceptance Criteria
- [ ] Project `sc/lab/tracks/<name>.tracklab.json` (format 1, schema `tracklab.schema.json`): name, about, tempo,
      swing, genre, `frameFrom` (a stem track whose frame is copied on Publish), chapters, slots (library stems,
      empty allowed), `launchkey` (library rig or a draft rig in the project), optional `select`
- [ ] `sc/lib/tracklab.scd` loads a project as a track (like `stemlab.scd`); `engine.scd` and `render.scd` accept it
- [ ] Player: projects under Lab; New (pick a template track), Load, Save, Save as, Publish (writes
      `sc/tracks/<id>/<id>.track`, `<id>-frame.scd`, the rig if it is a draft; never over existing files)
- [ ] Stem drawer on empty slots: a pick reloads the project with the slot filled (short gap); filled slots swap at
      the bar line as in the stem swap
- [ ] Track settings panel: tempo, swing, genre (genres.md), chapters (from the template frame), about
- [ ] Launchkey panel: keys sound, knob targets, per-pad picker (samples in `samples/`, fonts), pad gain; a change
      plays on the next hit or key (reload of the rig only, the columns keep playing)
- [ ] Published track passes `check-stems`, loads in the catalogue and plays
- [ ] Feature tests: project load, empty slot filled, rig change, Publish (temp dir)

## Technical Details
Reuse `stem-drawer.mjs`, `stem-swap.mjs`, `selection.mjs` (kind `column`, plus a new kind `pad` / `lk-knob` for the
Launchkey panel), `stem-lab.mjs` routes as the model for `/lab/tracks/…`. Labels follow the project rules.
