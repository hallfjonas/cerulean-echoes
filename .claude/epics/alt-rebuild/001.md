# Task: Device tests: DAW mode, NRPN faders, Launchpad MK3

## Description
DAW mode itself is measured (2026-11-23, PR #111). Measure what is still open, with the user at the devices, and pick
route A (DAW pages) or B (own custom mode + DAW mode), see the PRD's Constraints. Small SC script
(`sc/tools/alt-device-test.scd`, built on `midi-trace.scd`) that logs every message with its port and leaves DAW mode
off on exit.

## Acceptance Criteria
- [ ] One fader set to 14-bit NRPN in Components (slot 3), DAW mode on and CC 30 = slot 3: messages and value range recorded
- [ ] DAW pages: any way to get 14-bit faders (guide, Components, sysex) checked and recorded
- [ ] Route A or B chosen with the user, written into the PRD
- [ ] Launchpad: model (Mini MK3 or X), programmer-mode enter/exit, pad notes, side buttons, LED messages recorded
- [ ] Decisions with the user: fallback if DAW mode fails; where Tonic, Scale and Echo time go on the chosen route; start state (amplitudes not at 0)

## Technical Details
No track code. Script exits cleanly (DAW mode off) also on Cmd-period.
