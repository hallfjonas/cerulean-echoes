# Task: Launchpad: device, pins, LEDs

## Description
Launchpad MK3 as a device kind: found by port name, put into programmer mode, pads reported to the track as
`(row, col)`, LEDs set by the track with a rate cap; programmer mode left on exit.

## Acceptance Criteria
- [ ] Launchpad found (port name from 001), missing device = no error
- [ ] Pad press → track hook `lpPad(row, col)`; side buttons → `lpSide(n)`
- [ ] LED API: colour + brightness per pad, batched, ≤ 20 updates/s
- [ ] Clean exit: LEDs off, back to the default mode

## Technical Details
`sc/lib/controls.scd` device table plus a small `sc/lib/launchpad.scd` if the code grows past a few dozen lines.
