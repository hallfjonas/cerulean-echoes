# Task: Movement and the pin matrix (incl. Arp)

## Description
LFO 1/2 (shape square → triangle, low / high range, clock sync), Random S&H (offset, slew, clock multiples), Outline
envelope follower on the voice gates (release, invert); a 4 × 16 pin matrix summing sources into destination buses;
Arp triggers OSC2-5 in turn from the pinned source.

## Acceptance Criteria
- [ ] Each of the 16 destinations reacts to each of the 4 sources (feature test: pin on → destination bus moves)
- [ ] Pins add up on one destination; depth = source Amplitude
- [ ] LFO high range reaches audio rate (FM/AM audible on Freq / Amp)
- [ ] Sync on: LFO phase reset per beat; Random at 1/8 … 8 of the clock
- [ ] Arp: with amplitudes low, a pinned LFO plays OSC2-5 in an order that changes with shape and amplitude

## Technical Details
Control-rate buses except the FM/AM paths. Source activity values exposed for the Launchpad pulse (003).
