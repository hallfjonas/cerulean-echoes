# Task: Sounds: oscillators, noise, Alter

## Description
The ALT voice and Alter as SynthDefs in `sc/sounds/` (one sound per file): OSC1 sine, OSC2-5 tri/saw, noise, two
filters in series with Lo/hi crossfade, Resonance up to self-oscillation, Ripples; stereo delay with feedback to
infinite, time, More. Every modulatable parameter takes a control bus (and an audio-rate input for Freq / Amp).

## Acceptance Criteria
- [ ] Sounds load in `npm run verify-sc`; at start state the chain sounds without clipping
- [ ] Lo/hi gives LP → mid scoop → HP; Resonance max self-oscillates without blowing up
- [ ] Echo feedback at max holds a loop without growing
- [ ] No reverb

## Technical Details
Read the ALT manual's Alter section first (https://www.cymaforma.com/pages/alt-manual). Research how BBD delays and
Sallen-Key filters sound before choosing UGens; cite sources in the sound files' comments.
