# Task: Spike: LC XL 3 Track ◄ ► buttons

## Description
Find out what the LC XL 3 Track ◄ ► buttons (and Page ▲ ▼, for later) send while the device is in custom mode 1 or 2:
nothing, a CC or note on the `LCXL3 … MIDI` port, or only on the `DAW` port; whether Novation Components can give
them a CC in a custom mode; whether a press changes the device's mode or page.

## Acceptance Criteria
- [x] A small MIDI monitor (SC `MIDIFunc.trace` script in `sc/tools/` or a Node script in `tools/`) that lists every
      message from every LCXL3 port with its port name
- [x] The user presses Track ◄, Track ►, Page ▲, Page ▼ in Mode 1 and Mode 2 (and once with the DAW port open);
      results written into `midi-layouts/devices.md` (port, message, channel, number, value on press/release)
- [x] Decision recorded in the epic: Track ◄ ► usable as is, usable after a Components change (which), or not usable
      (then the fallback is chosen with the user and task 003 updated)

## Technical Details
No track or engine changes. Needs the user and the device.

## Result (2026-11-21)
- Monitor: `sc/tools/midi-trace.scd` (SC `MIDIFunc`, every input with its port name).
- Mode 1 and Mode 2 (device `LCXL3 Jonas`): knobs arrive on `MIDI Out` (Mode 1 CC 21 / 22, Mode 2 CC 61, channel 1);
  Track ◄ ►, Page ▲ ▼ send nothing on `MIDI Out` or `DAW Out`, and nothing changes on the device.
- Novation Components: Track and Page cannot be assigned in a custom mode.
- Novation's programmer's reference (p. 7): Page, Track, Record, Play, Solo/Arm and Mute/Select are unused in
  standalone mode; they report on the DAW port only in DAW mode.
- Decision (user): the epic stays in standalone (MIDI) mode and does not use Track / Page. Next track in a set =
  Mode 2, column 8, button 1 (CC 92); task 003 rewritten. DAW mode is a separate proposal: PR #75
  (`docs/reference/lcxl3-daw-mode.md`, report and open device tests).
