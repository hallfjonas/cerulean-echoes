# Task: Converter tool from the pilot

## Description
Turn the pilot into `npm run producer -- <file.mid> [--map <map.json>]`: MIDI + mapping file → live track, design
stub and perform script. Proven by regenerating 012.

## Acceptance Criteria
- [ ] `tools/producer/make-track.mjs` + `npm run producer` script; writes to `tracks/<genre>/NNN-<name>/` and
      `tools/trajectory/perform/<track>/` without overwriting existing files (new name or `--force` asked)
- [ ] `012-edm-snippet-map.json` holds every pilot decision (columns, voices per program, sections, Chapter,
      performance arc)
- [ ] Without a map: sensible defaults (parts by note count to columns, GM program family → voice, sections from
      markers or every 8 bars, marker bar n → script bar n - 1) and a map file written for the user to edit
- [ ] Regenerated 012 vs hand-built 012: per-stem events equal (`npm run compare -- … --stem`), or differences listed
      and accepted by the user; hand-built 012 is not overwritten (output to a temp path for the comparison)
- [ ] Generated track passes `npm run verify` with no hand edits

## Technical Details
- Template-based: the track skeleton comes from the pilot, with marked slots for parts, voices and sections.
- Reuse `midi-read.mjs`; no Strudel evaluation in the generator.
- Program changes inside a part map to a voice change at that bar (none in the pilot; 006 needs it).
