# Task: MIDI reader and per-bar dump

## Description
Read the Guitar Pro MIDI exports and print each part as mini-notation per bar, so the pilot never types notes by
hand. Move the EDM and Classical `.mid` files from this epic folder to their track folders.

## Acceptance Criteria
- [ ] `tools/producer/midi-read.mjs` returns { tempo, timeSignatures, markers, bars, tracks: [{ name, programs, notes }] };
      `programs` lists each program change with its bar; notes have bar, beat, length (bars), pitch, velocity;
      channels of one Guitar Pro track merged
- [ ] `node producer/midi-read.mjs <file> --dump [--track n] [--bars a-b]` prints note names per bar as mini-notation
      (rests, chords as `[c3,e3]`, ties across bar lines kept as length)
- [ ] Summary of both files matches the PRD source table (tempo, bars, markers, program changes, note counts per track)
- [ ] Tempo changes and time signatures other than 4/4 are reported as unsupported (warning), not silently flattened
- [ ] Sources moved: `tracks/edm/012-edm-snippet/gp-edm-snippet.mid`,
      `tracks/classical/013-hope-for-niklas/gp-classical.mid`; `GP Slow Rock.mid` stays here for 007

## Technical Details
- No dependency unless parsing gets fiddly (`@tonejs/midi` is the fallback; ask first).
- When skipping a variable-length block, read the length before adding it to the position (`p += vlq()` reads `p`
  before `vlq` moves it).
- Quantise to the smallest grid that loses no note (report the grid per part): EDM drums and Spur 5 need 1/64
  (rolls); nothing in either file is a triplet.
- GM drum notes printed by name (35/36 kick, 49/57 crash …) for the drum part.
