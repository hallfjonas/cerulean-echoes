# Task: MIDI reader and per-bar dump

## Description
Read the Guitar Pro MIDI exports and print each part as mini-notation per bar, so the pilot never types notes by
hand. Move the three `.mid` files from this epic folder to their track folders.

## Acceptance Criteria
- [ ] `tools/producer/midi-read.mjs` returns { tempo, timeSignatures, markers, bars, tracks: [{ name, programs, notes }] };
      notes have bar, beat, length (bars), pitch, velocity; channels of one Guitar Pro track merged
- [ ] Pickup bar handled (Slow Rock starts with 1/4, then 4/4): bar 1 = first full bar, pickup reported separately
- [ ] `node producer/midi-read.mjs <file> --dump [--track n] [--bars a-b]` prints note names per bar as mini-notation
      (rests, chords as `[c3,e3]`, ties across bar lines kept as length)
- [ ] Summary of all three files matches the table in the PRD (tempo, bars, note counts per track)
- [ ] Sources moved: `tracks/rock/012-slow-rock/GP Slow Rock.mid`, `tracks/classical/013-hope-for-niklas/GP Classical.mid`,
      `tracks/edm/014-edm-snippet/GP EDM Snippet.mid` (renamed without spaces)

## Technical Details
- No dependency unless parsing gets fiddly (`@tonejs/midi` is the fallback; ask first).
- Quantise to the smallest grid that loses no note (report the grid per part); triplets → `{}` / `@` weights.
- GM drum notes printed by name (36 kick, 38 snare, 42 hh …) for the drum part.

None.
