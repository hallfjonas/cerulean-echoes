# Task: Track Designer view

## Description
A player-like view to open one stem track and edit its stems and genre, then Save or Save as copy.

## Acceptance Criteria
- [ ] Same shell as the player (MIDI panel with the LC view, visuals, transport); the side panel holds the sections
      Track, Stems, Launchkey (placeholder until 003), Save
- [ ] Track section: list of `sc/tracks/` stem tracks to open; id, tempo and about read-only; genre picker from
      `docs/reference/genres.md`
- [ ] Every stem track in `sc/tracks/` opens, plays and shows its 14 slots
- [ ] Column click (both LC modes) opens the stem drawer: Replace on a filled slot, Remove, Add on an empty slot; a
      change swaps at the bar line when the strip fits, else the track reloads with a short gap
- [ ] `genre` field in the track file, read on open, written on Save
- [ ] Save writes track file (slots, genre) and, once 003 lands, the rig, in place; Save as copy writes
      `sc/tracks/<new-id>/` (track, frame, rig) and refuses an existing id; `check-stems` passes on both
- [ ] Unsaved changes marked; leaving with unsaved changes asks
- [ ] Feature tests: track open, replace / remove / add, genre save, Save as copy (temp dir)

## Technical Details
Reuse `stem-drawer.mjs`, `stem-swap.mjs`, `selection.mjs`. Empty slots need `stemtrack.scd` to load a slot added
after start (short reload). Save in place touches only the opened track's files. Labels follow the project rules.
