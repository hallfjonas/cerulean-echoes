# Task: Launchkey section

## Description
Change the Launchkey keys sound and single drum pads of the opened track and save them into its rig.

## Acceptance Criteria
- [ ] Keys sound picker (sounds of `sc/lib/lkkeys.scd`); a change plays on the next key press
- [ ] 16-pad grid with a per-pad sample picker (`samples/` and the fonts) and a level per pad; a change plays on the
      next hit (reload of the rig only, the columns keep playing)
- [ ] Knobs 1-8 listed read-only (label, about)
- [ ] Save writes keys and pads into the track's rig; a track without a rig gets one extracted from its frame code
      on Save as copy; no frame code is edited
- [ ] `@ctl` texts for rig knobs and pads, short, English
- [ ] Feature tests: keys change, pad change, rig saved (temp dir)

## Technical Details
New selection kind `pad` in `selection.mjs`. Rig changes go through `lkrig.scd` (task 001). Existing rig files are
not overwritten by Save as copy; a changed rig is written as a new rig file.
