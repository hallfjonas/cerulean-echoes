# Task: Video upload and mux (server)

## Description
`recording.mjs` accepts video chunks for an open recording and, on finish, muxes picture and WAV into `<name>.mp4`.

## Acceptance Criteria
- [ ] `PUT /recording/<track>/<name>/video` appends a chunk (same guards: own page, open name, 2 GB free, chunk size limit)
- [ ] `POST …/finish` with `video: { offsetSeconds, mime }` runs ffmpeg (niced) and writes `<name>.mp4` with the WAV's sound
- [ ] Sidecar gains `video: { file, width, height, fps, seconds, offsetSeconds }`, or `video: { error }`; old sidecars unchanged
- [ ] Raw capture deleted after a good mux, kept on failure; ffmpeg missing gives a clear message and leaves the WAV intact
- [ ] `check-recording.mjs` covers a synthetic video plus WAV roundtrip

## Technical Details
Even dims and first-frame size through an ffmpeg scale/pad filter. `-itsoffset` from `offsetSeconds`. Copy the video stream when it is already H.264.
