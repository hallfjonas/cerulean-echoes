# Task: Relative knobs toggle

## Description
A player setting that makes all knobs (LC and LK) relative instead of absolute.

## Acceptance Criteria
- [ ] Setting `relativeKnobs` in `tools/trajectory/settings.mjs` (toggle, key, tip), default off, saved in the browser
- [ ] The value reaches SC as `/ce/relative` on change, on every load and after an SC restart
- [ ] On: a knob message changes the stored value by the difference to the knob's previous raw value, clipped to 0-1;
  the first message after switching on only records the raw value
- [ ] Applies to knobs only: LC knob CCs (rows 13-35, Mode 2 +48, column 8) and Launchkey knobs (21-28, 31-38);
  faders, buttons and the mod wheel stay absolute
- [ ] Hardware path only (`ce.midiCC`): UI, auto-perform and takes still set absolute values
- [ ] Feature tests: SC test with scripted raw values; Node test for the setting and its routing

## Technical Details
Files: `sc/lib/controls.scd` (`midiCC`, flag, `lastRaw`), `sc/lib/ui.scd` (`/ce/relative` in), `tools/trajectory/
settings.mjs`, `sc-link.mjs`, `server.mjs`, `tools/sc-test/run.scd`. The value shown in the panel follows the stored
value as today. Hardware-relative encoders: not in this task.
