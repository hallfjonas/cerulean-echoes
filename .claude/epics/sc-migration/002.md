# Task: SC engine in the player

## Description
The player plays SC tracks: pick, Play, Stop, switch, with the MIDI panel showing SC's controller state.

## Acceptance Criteria
- [x] `tools/trajectory/engine-sc.mjs` implements `{ ready, load, stop, cycle, cps, output }`
- [x] `sc/ui/bridge.mjs` folded into `server.mjs` as `sc-link.mjs` (one process, one port); the bridge stays only for
      IDE play with `live.scd` (own ports, both can run)
- [x] SC: `/ce/load <id>`, `/ce/stop`; clock from `/ce/beat`
- [x] `catalogue.mjs` lists `sc/tracks/*/*.scd` with `engine: 'sc'`; the page picks the engine per entry
- [x] MIDI panel shows SC's `/ce/state` / `/ce/ccs`; controllers stay direct to SC
- [x] Feature tests: track list, load/play/stop/switch, controllers reach the track, MIDI panel values

## Done (notes)
- SC host `sc/engine.scd`: own sound server (57140) and OSC port (57131); no input device pinned (a headless boot
  hangs on the mic permission); new clock per load (bar 0 = load).
- Catalogue: SC tracks under the plain id, frozen Strudel copies as `<id>-strudel` with `base` (scripts from
  `perform/<id>/`).
- Player: Record and auto-perform say "not built yet" for SC tracks (005, 004).
- Tests: `trajectory/sc-link.test.mjs` (track list, start/play/click/switch/stop/quit, nothing left behind).

## Technical Details

leave nothing playing.
