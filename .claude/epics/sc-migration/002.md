# Task: SC engine in the player

## Description
The player plays SC tracks: pick, Play, Stop, switch, with the MIDI panel showing SC's controller state.

## Acceptance Criteria
- [ ] `tools/trajectory/engine-sc.mjs` implements `{ ready, load, stop, cycle, cps, output }`
- [ ] `sc/ui/bridge.mjs` folded into `server.mjs` (one process, one port); `sc/ui/` page retired or redirected
- [ ] SC: `/ce/load <id>`, `/ce/stop`; clock from `/ce/beat`
- [ ] `catalogue.mjs` lists `sc/tracks/*/*.scd` with `engine: 'sc'`; the page picks the engine per entry
- [ ] MIDI panel shows SC's `/ce/state` / `/ce/ccs`; controllers stay direct to SC
- [ ] Feature tests: track list, load/play/stop/switch, controllers reach the track, MIDI panel values

## Technical Details
OSC codec from `bridge.mjs`; WebSocket to the page. Switching from an SC track to a Strudel track and back must
leave nothing playing.
