# Task: LEDs and screen

## Description
In DAW mode the LC shows only what the engine draws. Draw today's colours, the mode and track, and the name and value
of a control while it moves (PRD FR5, FR6, FR12).

## Acceptance Criteria
- [ ] One repaint call per device (bottom buttons, knob LEDs, screen, knob positions), used on enable, mode switch and
      track load
- [ ] Colours per mode as measured in 001; no new LED meanings
- [ ] Stationary display: mode (`jojo` / `jonas`) and track name, lower case
- [ ] Temporary display on every knob or fader move: the control's `@ctl` name and its value; timeout set once
      (ch 7 CC 113)
- [ ] No more than one screen message per control change per device (no flood on a fast fader move)
- [ ] Feature tests: repaint sends to every LC; a knob move writes name and value (simulated port)
- [ ] Checked on the device by the user: colours as today, the screen readable while playing

## Technical Details
Sysex as in `docs/reference/lcxl3-daw-mode.md`. The `@ctl` names come from the track's tags (`~ce.stemTrackTags` for
stem tracks, the `.scd` comments for the others), already read for the UI.
