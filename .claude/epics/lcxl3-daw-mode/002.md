# Task: Driver layer

## Description
Move today's port handling behind one driver per device kind, with no change in behaviour, so the DAW driver (003)
is an added file and a future controller is one more.

## Acceptance Criteria
- [x] A driver interface in `sc/lib/`: match a port name, MIDI in → engine controls (`setCC`, `setLkCC`, `lkPlay`,
      presses), engine out → device (knob positions; LED and screen calls that do nothing in the custom driver)
- [x] `lcxl3-custom` driver: today's LC path (knob value scaling, pickup, `lcModeSwitch`, knob feedback to MIDI In)
- [x] `launchkey-mk4` driver: today's Launchkey path (keys, pads ch 10, mod wheel pickup, knobs)
- [x] `~ce.midiKinds` becomes the driver list; unknown ports are still listed and ignored
- [x] Control ids unchanged (CC 5-100, Launchkey CCs); takes, scripts, the web view and `@ctl` untouched
- [x] `npm test` green with no test changed except where a test reached into removed internals
- [ ] Played once by the user on one track with an LC and the Launchkey: nothing feels different

## Technical Details
`sc/lib/controls.scd` keeps the shared engine parts (setCC, latches, pickup, knob scaling maths). Driver file names
decided here: `sc/lib/lcxl3-custom.scd`, `sc/lib/launchkey-mk4.scd` (the DAW one: `sc/lib/lcxl3-daw.scd`), interface
in `controls.scd` (`~ce.addDriver`). Keep it small: two drivers today, the DAW one in 003; no plug-in loader, no config file.
