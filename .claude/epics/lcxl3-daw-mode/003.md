# Task: DAW driver: input and knob feedback

## Description
The `lcxl3-daw` driver: the engine enables DAW mode on every LC and plays every track through the DAW port, with
Mode 1 / Mode 2 done by the engine (PRD FR1-FR4, FR8, FR9).

## Acceptance Criteria
- [ ] Enable on connect (also plugged in later, the 2 s scan): `9F 0C 7F` to DAW In, then the DAW page from 001;
      disable (`9F 0C 00`) on engine exit and `ShutDown`; nothing sent in muted runs
- [ ] DAW Out is an `lc` port; knobs ch 16 CC 13-36, faders ch 16 CC 5-12, bottom buttons ch 1 CC 37-52 into the
      engine; Mode 2 + 48, column 8 through `ccAlias`
- [ ] Mode per device, switched by the buttons from 001; a switch runs the fader handover and resends that device's
      knob positions for the new mode
- [ ] Knob feedback to DAW In ch 16 with the device's current-mode numbers (Mode 2: − 48); never on ch 1
- [ ] DAW-only buttons (`page-up`, `page-down`, `track-left`, `track-right`, `solo`, `mute`, `record`, `play`,
      `shift`, `small`) reach the UI as named presses, no jobs
- [ ] Fallback: no DAW port or no mode report within a second → logged, the custom driver is used
- [ ] DAW Fader Pickup as 001 decided
- [ ] Feature tests (`tools/sc-test/run.scd`, simulated ports): DAW port detected, Mode 2 offset, knob feedback
      channel and numbers, mode handover, fallback without an answer
- [ ] Played by the user with one LC on 009 and 018, both modes

## Technical Details
Builds on the driver interface from 002. Two LCs: one mode each (one on Jojo, one on Jonas).

## Dependencies
001 (page, buttons, knob feedback, pickup), 002 (drivers).
