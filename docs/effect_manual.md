
## Effects

### Attack, Decay, Sustain
```
volume
↑
│       attack
│        /\
│       /  \ ← decay
│      /    \
│     /      ─────────  sustain --
│    /                             \
│   /                               \ ← release
└───────────────────────────────────────────────→ time
```

### Orbits &
- Orbit: controls which effects bus (“orbit”) a sound is sent through



## Ocillator Shapes
| Waveform   | Shape             | Sound                            | Typical use              |
| ---------- | ----------------- | -------------------------------- | ------------------------ |
| `sine`     | smooth curve      | Pure, soft, round                | Sub bass, pure tones     |
| `triangle` | linear up/down    | Softer than saw, slightly hollow | Bass, pads, mellow leads |
| `sawtooth` | ramp + drop       | Bright, buzzy, rich              | Pads, leads, bass        |
| `square`   | abrupt high/low   | Hollow, punchy, retro            | Bass, leads, arps        |
| `pulse`    | asymmetric square | Nasal, edgy                      | Leads, bass              |
| `noise`    | random            | Hiss / texture                   | Percussion, atmosphere   |
