# Features

One page per feature, in plain English. Each page says what it is, when to use it, how, what to know and what is
related. New here? Start with [getting started](../getting-started.md).

- [Player](player.md) - plays any track or board on localhost, with the visuals
- [Live tracks](live-tracks.md) - the one-file tracks you play with the controllers
- [Controllers](controllers.md) - the Launch Control XL 3 and the Launchkey, and what the knobs mean
- [Auto-perform](auto-perform.md) - a script plays a track without hardware
- [Lab boards](lab-boards.md) - test and compare sounds before they go into a track
- [Sets](sets.md) - several tracks played as one set
- [Sound lab](sound-lab.md) - Sample Designer, Stem Designer and stem swap in the player
- [Stems](stems.md) - one LC column as a file: format, naming, add-ons, stem tracks (SuperCollider)
- [Samples and sounds](samples-and-sounds.md) - adding audio and checking that sounds load
- [Checks](checks.md) - tools that test a track without a browser
- [Visuals](visuals.md) - the looks and settings of the picture
- [Producer mode](producer-mode.md) - Guitar Pro songs as live tracks
- [Claude skills](claude-skills.md) - what to say to Claude Code for each job
- [strudel.cc](strudel-cc.md) - playing a track in the Strudel web editor
