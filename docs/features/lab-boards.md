# Lab boards (retired)

The Strudel lab boards (test benches for one instrument or track role) were removed on 2026-11-21. Strudel is
deprecated; new sound work goes to the SuperCollider sound lab (Stem Designer and Sample Designer).

- What was decided on the boards, and why: `docs/reference/lab-lessons.md`.
- The boards themselves: git history, `git checkout a69f511 -- lab/<folder>`.
- The ear-training tutorials (`lab/tutorials/`) were removed on 2026-11-26: `git log --diff-filter=D -- lab/tutorials`.

See the [sound lab](sound-lab.md).
