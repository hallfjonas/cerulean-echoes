# Producer mode

## What it is
Producer mode turns a Guitar Pro song (exported as a MIDI file) into a live track plus an auto-performance. Every part
plays its notes as written, re-voiced with this project's sounds, in the usual live track layout. Song bar 1 is
cycle 0 and one bar is one cycle. The result is a normal one-file live track, so every controller stays optional.

Two songs exist so far: `012-edm-snippet` (built by hand, the model for the tool) and `013-hope-for-niklas`
(generated by the tool).

## When to use it
When you have a song written in Guitar Pro and want to play it with the controllers like any other live track, or
watch it play itself in the player.

## How to use it
1. In Guitar Pro: File, Export, MIDI. Name the file `gp-<song>.mid` and put it in the track folder
   `tracks/<genre>/NNN-<name>/`.
2. Look at the file first: `node producer/midi-read.mjs <file.mid>` (in `tools/`) prints tempo, bars, markers and the
   parts of the song, plus warnings.
3. Generate the track: `npm run producer -- <file.mid>` (in `tools/`). It writes the track, a design stub, a map file
   and a perform script.
4. Change a decision (which part goes to which column, which voice, which chapters) in the map file
   `<track>-map.json`, then run again with `--map <map.json> --force`.
5. Check the result with `npm run verify -- <track>` and `npm run audibility -- <track>`.

The workflow around the tool (design gate, listening rounds, lessons back into the tool) is the skill `/producer`. All
options and the map format are in [tools/producer/README.md](../../tools/producer/README.md).

## Good to know
- A generated track is changed through its map file, not by editing the track. The next run would overwrite the edit.
- Nothing is overwritten without `--force`, so a filled-in design survives a re-run.
- Not supported yet: tempo changes, time signatures other than 4/4, pickup bars, triplets, lyrics and bends. The tool
  warns or stops. See `.claude/prds/producer-slow-rock.md`.
- New sounds show as "not checked yet" in `samples/sounds.json` until you run
  `node strudel-sim/check-sounds.mjs <track>`.
