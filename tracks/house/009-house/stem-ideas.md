## Research round 2a: groove and existing code (2026-11-07, sources below)
- Strudel source code read: `nudge` has no effect in the browser (OSC only); micro-timing via `.late()` / `swingBy`.
  `swingBy(x, 8)` at 1 bar per cycle = MPC swing 0.5 + x/2 → 54 % = `swingBy(0.08, 8)`, 58 % = `swingBy(0.16, 8)`.
- Strudel example tunes (Felix Roos, website/src/repl/tunes.mjs): "Festival of fingers" (Euclid chords + quiet
  octave shadow via `off(1/7, …)`, anticipation via `early`), "Belldub" (`iter(4)` + answer in the fifth via
  `off(1/3, add(7))`, `degradeBy(.2)`, voice 8 bars on / 8 off via `mask`), "Lounge sponge" (`fast(2/3)` +
  `off(".25 .125", add("<2 4 -3 -1>"))`), "Arpoon" (`lastOf(4, fast(2))` phrase end, accents via `gain`).
- `ribbon(seed, len)`: cuts out a piece of randomness and repeats it → fixed riff, seed = preset;
  `wchooseCycles`: weighted choice of whole motifs per bar (kindohm: generative on motif/rhythm level, not note by note).
- Groove: MPC swing 54–58 %; stabs leave the main beats free, stress off-16ths, short/long alternating, bar 4
  slightly different, bar 8 contrast (Attack "Levelling up your chord stabs"); ghost notes 20–35 % velocity; motif
  development: repetition, sequence, fragment, rhythmic shift, question–answer (Marsalis study).
- "Escravos De Jo" (Bandcamp credits Joe Claussell): guitar, trumpet (Winston Byrd), flute (Talib Kibwe),
  percussion (Claussell); "a deep jam with live musicians". A sax is not documented in the credits.
- Ideas to try first: (1) fixed random riff via `ribbon`, good seeds as presets;
  (2) bar 2 = variation, bar 4/8 = fill (`lastOf`); (3) self-answer via `off(3/16, add(…))`; (4) main beats
  free, off-16ths stressed, short/long via `clip`; (5) swing 56 % + accents only on the top voices; (6) motif library
  via `wchooseCycles`; (7) brass/flute slightly behind the beat (`late`); (8) pauses: `mask` / `someCyclesBy`.
Sources: codeberg.org/uzu/strudel (tunes.mjs, pattern.mjs, signal.mjs, controls.mjs), strudel.cc/learn/time-modifiers,
uzu.lurk.org/t/generative-strategies-and-workflows/3353, attackmagazine.com (levelling-up-your-chord-stabs,
