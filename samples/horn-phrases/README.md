# horn-phrases — real recorded wind phrases for lab/melodie/melodie-3 (track 009, Jonas 4)

Cut from longer free improvisations at rests (or at the end of a long note), only calm ones kept (few, long notes:
≤ 3.2 notes/s, a note ≥ 0.5 s, ≥ half the time in notes ≥ 0.3 s, no scale runs, no notes outside A dorian / A aeolian),
moved into A by varispeed (pitch and tempo together, like a sampler; shift = semitones), evened to −20 dBFS RMS
(peaks ≤ −1 dBFS), 15 ms fade-in, 100–150 ms fade-out, mono FLAC. Source: the Freesound HQ previews (128 kb/s MP3;
the originals need a login). Pitch analysis: own YIN in numpy; selection by numbers, NOT heard.
Scripts: tools/phrase-cut/ (analyse.py, cut.py, see its README).
