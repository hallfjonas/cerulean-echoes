# vcsl-keys

Notes around the Am9 chord for lab/keys/house-keys-lab-17, from the Versilian Community Sample Library (VCSL,
https://github.com/sgossner/VCSL, CC0): Steinway B and Kawai grand, Yamaha upright, vibraphone. Trimmed to 3 s
(50 ms fade), FLAC 44.1 kHz / 16 bit. Hosted here because browsers refuse VCSL's raw GitHub files (a comma in the
folder names breaks the Content-Disposition header) and jsDelivr refuses some of them (package over 50 MB).
File names as in VCSL.
